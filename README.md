# 대화 사기 단계 감시 앱 (가칭)
> 저장소: `securityapp` · 앱 이름은 가칭이며 확정되면 바꿉니다.

카카오톡 메시지 알림을 **인터넷 연결 없이 기기 안에서만** 분석해, 대화가 투자 리딩방·로맨스 스캠 같은 사기의 위험한 흐름에 들어서면 본인에게 경고하는 안드로이드 앱입니다.

단일 문자의 스미싱 링크를 판별하는 서비스는 이미 많습니다. 이 프로젝트는 그 이후, **카카오톡으로 옮겨 가 몇 주에 걸쳐 신뢰를 쌓은 뒤 돈을 요구하는 대화의 흐름**을 다룹니다.

## 현재 상태 (2026-10-21)

| 작업 단계 | 내용 | 상태 |
|---|---|---|
| 0. 사전 점검 | 데이터 확보, 과제 규칙·장비 확인 | 진행 중 |
| 1. 데이터·단계 체계 검증 | 평가 세트 구축, 신호 체계 가설 검증 | 진행 중 — 일반 대화 43건 확정, 사기 재구성 10건 잠금, 세 모델 자유 메모로 신호 체계 v2 수정, 다음은 라벨 기준표 |
| 2. 판정 엔진 + 재생 평가 | 순수 Kotlin 엔진, 3단 비교 | 예정 |
| 3. 의미 검증 | 기준선 대비 성능, 대상자 반응 | 예정 |
| 4. 엔진 개선 | 필요 시 소형 모델 비교 | 예정 |
| 5. 안드로이드 앱 적용 | 알림 수집, 경고 화면, 보안 대책 | 예정 |

앱을 마지막에 만드는 이유: 판정이 실제로 의미가 있는지 먼저 확인하기 위해서입니다. 자세한 기준은 [docs/plan.md](docs/plan.md) 7장에 있습니다.

## 설계 핵심

- **흐름·행동 신호로 판정**: 단어("계좌", "투자")가 아니라 *그 말이 무엇을 하려는지*(이동 요구, 수익 보장, 비밀 유지 요구 등)를 감지하고, 대화방에서 그 행위들이 어떻게 쌓이는지로 판정합니다.
- **인터넷 권한 없음**: 대화가 기기 밖으로 나가지 않는다는 것을 앱 권한 목록으로 누구나 확인할 수 있게 합니다.
- **정직한 평가**: 공개 데이터에 한국어 메신저 사기 대화가 없어, 공개 사례를 뼈대로 재구성하고 메시지마다 출처를 표시합니다. 단어 기준선과 비교해 흐름 판정의 효과를 따로 보고합니다.

## 폴더 구조

```
.
├── docs/                 계획서, 결정 기록, 데이터 출처
│   └── labeling/         자유 메모·라벨링 절차와 결과
│       └── memo_results/ 세 모델(Grok·Claude·ChatGPT)의 자유 메모 원본
├── data/
│   ├── README.md         데이터 받는 법 (외부 데이터 원문은 저장소에 없음)
│   └── eval/
│       ├── normal_selected_ids.csv   평가 세트 일반 대화 43건의 ID 목록
│       └── scam/                     사기 재구성 10건 (.jsonl + 읽기용 .md, 커밋 9e40dca에서 잠금)
└── tools/
    ├── aihub/
    │   └── extract_candidates.py     AI Hub 일상 대화 데이터 → 후보 추출·검토 목록·재생 형식
    └── scam/
        ├── check_case.py             재구성 사례 점검 + 읽기용 표 생성
        └── make_blind.py             라벨러용 가림판 생성
```

예정: `engine/` (판정 엔진, 순수 Kotlin), `eval/` (재생 평가기), `app/` (안드로이드 앱)

## 데이터 사용 고지

이 프로젝트는 과학기술정보통신부와 한국지능정보사회진흥원(NIA)이 구축한 AI-Hub의 **「주제별 텍스트 일상 대화 데이터」**를 사용합니다. 데이터 원문은 이용 약관(제3자 제공·재배포 금지)에 따라 저장소에 포함하지 않습니다.
