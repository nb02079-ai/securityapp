# 개발용 합성 대화 2차 (작업 4-1)

1차([01](01_synthetic_prompt.md))와 같은 원칙입니다. 평가 사례, 가림판, 라벨 기준표는 주지 않습니다. 2차는 **말투와 표현의 폭**을 늘리는 것이 목적입니다. engine-v1은 표현이 조금만 달라도 신호를 놓쳤습니다 ([결과 3.3](../stage2_results_v1.md)).

## 진행 방법
1. 모델마다 **기억을 끈 새 대화**(ChatGPT 임시 채팅, Gemini 활동 기록 끔, Claude는 이 프로젝트 밖 새 대화)를 엽니다. 1차 대화와 섞이지 않게 합니다.
2. 아래 지시문의 `[맡을 유형]`에 그 모델의 줄을 넣어 붙여 넣습니다.
3. 결과를 `dev2_<모델>.csv`로 저장해 이 세션에 올립니다.

| 모델 | 맡을 유형 (사기 8건 + 정상 4건) |
|---|---|
| ChatGPT | 사기: 주식 리딩방(무료방 → 유료방), 해외 거주자 로맨스 뒤 투자, 공모주·비상장주 배정, 손실 회복을 미끼로 한 2차 사기, 코인 지갑 연동 이벤트, 지인의 지인을 통한 투자 소개, 군 관계자 사칭 물품 배송비, 쇼핑 리뷰 미션 / 정상: 동창 단톡방 계모임 회비, 사내 주식 스터디 단톡방, 부동산 중개인과 계약금 대화, 연인 사이 여행비 나누기 |
| Gemini | 사기: 유명 투자자 사칭 강의방, 해외 거래소 가입 유도, 결혼 상대 소개 뒤 투자 권유, 대출을 받아 투자하라는 권유, 출금하려면 세금·수수료를 먼저 내라는 요구, 투자 동호회 운영자의 1:1 연락, 해외 택배 통관 대납, 고수익 재택 과제 / 정상: 형제 사이 부모님 병원비 나누기, 주식 앱 고객센터 상담, 중고 명품 직거래, 교회·동호회 헌금·회비 안내 |
| Claude | 사기: 선물·옵션 리딩, 로맨스 상대의 "함께 투자하자", 금융기관 직원 사칭 상품 권유, 코인 채굴기 위탁, 소액 수익을 먼저 주는 단계형 투자, 지인 사칭 급전 요청, 해외 취업 보증금, 경품 당첨 수수료 / 정상: 대학 동기 투자 정보 잡담, 이사 업체 계약금 안내, 친구에게 빌린 돈 갚기, 가게 사장님과 거래처 결제 대화 |

## 지시문

```
한국어 메신저(카카오톡) 대화를 직접 지어서 써 주세요. 사기 탐지 연구의 "개발용" 데이터이며, 실제 피해 사례를 그대로 옮기지 말고 새로 지어 주세요.

[맡을 유형]
(여기에 위 표에서 맡은 사기 8개와 정상 4개를 붙여 넣기)

[이번에 특히 지켜 주세요: 말투와 표현을 다양하게]
대화마다 아래 말투 중 하나를 골라, 12개 대화가 최대한 서로 다르게 해 주세요.
- 운영자·매니저의 공지체 ("금일 공지드립니다", "참여자분들께 알려 드립니다")
- 짧게 여러 번 끊어 보내는 반말·구어체, 오타·줄임말 섞기
- 번역기를 거친 듯한 어색한 말투 (해외 거주자를 자처하는 상대)
- 상담원·직원·담당자 말투 (정중하지만 절차를 강요)
- 돈 이야기를 돌려 말하기 ("참여하시려면 최소 단위가 있어요", "인증 한 번만 해 주시면", "확인되시면 화면 한 장만요")
- 숫자·금액을 여러 방식으로 쓰기 (500만, 오백, 5백, 5,000,000원, 0.5천)
같은 뜻도 대화마다 다른 표현으로 써 주세요. 예를 들어 "돈을 넣으라"는 말을 "참여", "충전", "증거금", "시드", "입금 인증" 등으로 다양하게 바꿉니다.

[대화 규칙]
- 대화마다 12~40개 메시지. 상대방과 "나"의 메시지를 모두 씁니다.
- 사기 대화는 흐름을 섞어 주세요. 바로 돈 이야기를 하는 대화, 오래 친해지는 대화, 돈을 보낸 뒤에도 계속되는 대화, "나"가 의심하거나 거절하는 대화가 고루 있어야 합니다.
- 정상 대화에는 돈·계좌·투자·입금 이야기가 자연스럽게 들어가야 합니다 (사기로 오해받기 쉬운 정상 대화).
- 한 사례 안에 대화방이 여러 개일 수 있습니다: 1:1, 단체방, 문자.
- 사진·파일은 [사진], [파일]로만 씁니다. 링크·계좌번호·전화번호·지갑 주소는 (링크), (계좌번호), (전화번호), (지갑 주소)로 가립니다.
- 실존 인물·회사·은행 이름은 쓰지 말고 OO은행, △△증권처럼 씁니다.
- 날짜는 첫 메시지를 0으로 한 "며칠째"로 적습니다.

[출력]
CSV 파일 하나로 주세요. 칸은 다음과 같습니다.
case,kind,type,seq,day,room,sender,is_user,text
- case: E01, E02 … (대화 번호)
- kind: scam 또는 normal
- type: 맡은 유형 이름
- seq: 대화 안의 메시지 순서 (1부터)
- room: 대화방 이름 (예: 1:1, 단체방, 문자)
- sender: 보낸 사람 표시 이름 ("나"의 메시지는 "나")
- is_user: "나"의 메시지면 true, 아니면 false
- text: 메시지 내용 (쉼표가 있으면 큰따옴표로 감싸기)
```

## 받은 뒤 (이 세션)
- 이 지시문의 예시 표현은 평가 문장과 5자 이상 겹치지 않는 것만 썼습니다 (작성 때 검사).
- 형식 점검과 평가 문장 겹침 검사(7자 이상)를 한 뒤 `data/dev/synthetic2/<모델>/`로 변환합니다 (`tools/dev/import_synthetic.py`).
- 사례 번호는 1차(D)와 겹치지 않게 E를 씁니다.
