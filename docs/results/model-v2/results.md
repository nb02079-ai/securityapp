## 4. 원인 (평가 후 분석, 모델은 바꾸지 않음)

1. **문턱을 작은 개발 세트에 맞춤**
   - 문턱은 개발 세트의 KorCCVi 일반 통화 107건에서 오탐 3건(2.8%)이 되도록 정했습니다.
   - 그때도 95% 신뢰구간은 1.0–7.9%로 넓었습니다. 107건으로는 3% 근처를 정확히 맞출 수 없었다는 뜻입니다.
   - 모델 점수가 0과 1 근처로 몰려 있어, 문턱을 조금만 옮겨도 오탐 수가 크게 바뀝니다. 개발 세트 문턱표에서도 확인됩니다. 0.8434에서 오탐 3건, 0.3680에서 10건입니다.
2. **일반 통화의 주제 차이**: KorCCVi 일반 통화(AI-Hub 전화망)는 금융과 먼 주제가 많습니다. 그래서 계좌·본인 확인·전화번호처럼 사기 통화와 겹치는 표현이 나오는 일반 통화가 학습에 적습니다.
3. **메신저**: 메신저 사기 학습 데이터가 41건(합성 33, 재구성 8)뿐입니다. 놓친 7건이 어떤 유형인지는 점수 파일로 따로 볼 수 있습니다.

## 5. 다음에 해 볼 것 (다음 버전용, 이번 결과에는 적용하지 않음)
- 문턱을 하나의 개발 세트로 정하지 않고, 교차 검증으로 여러 번 정해 평균을 씁니다. 또는 점수 보정(temperature scaling)을 거쳐 점수가 0과 1에 몰리지 않게 합니다.
