# model-v2 → ONNX 변환 기록 (5단계-1, 2026-11-18)

결론: **int8 ONNX(14.8MB)**를 앱에 넣습니다. 개발 세트에서 원래 모델과 대화별 경고 여부가 99.85% 같았습니다. 합격 기준은 99% 이상이었습니다.

## 변환
- 도구: `tools/model/export_onnx.py`
  - 변환 전에 원본이 [freeze.json](freeze.json)과 같은지 확인합니다.
  - torch 2.14의 dynamo 방식으로 opset 18 ONNX를 만들고, onnxruntime으로 가중치를 int8 동적 양자화합니다.
- **첫 시도 실패**: 기존 방식(TorchScript)으로 변환하니 같은 입력에서 점수가 0.00417 대 0.0000872로 달랐습니다.
  - 원인은 transformers가 패딩 마스크를 만드는 계산이 입력 하나에 맞춘 상수로 굳은 것입니다(TracerWarning).
  - dynamo 방식으로 바꾸고, 원본과 fp32의 차이가 0.001을 넘으면 멈추는 점검을 넣었습니다.
- 점검 문장 4개(배치 1·3, 패딩 있음/없음)에서 원본과의 최대 점수 차이: fp32 0.0000014, int8 0.076. int8은 문턱(0.84)에서 먼 낮은 점수 구간에서 차이가 났습니다.
