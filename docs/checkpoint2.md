## 2. 그래서 바꾼 것 (결정 27·28)

- **데이터**: AI가 만든 합성 대화 대신 **실제 사기 통화 전사문**을 씁니다. 금감원이 공개한 녹음 706건이고, KorCCVi v2에 들어 있습니다. 일반 대화는 두 가지를 씁니다.
  - KorCCVi 일반 통화 711건
  - AI-Hub 금융 콜센터 18,314건: 돈 이야기가 나오는 정상 대화입니다.
- **판정 방식**: 손으로 만든 규칙 대신 **소형 한국어 분류 모델**(KoELECTRA-small)을 주 방식으로 씁니다. 규칙은 비교 기준으로 남깁니다.
- **판정 기준**: 탐지율 90% 이상, 오탐률 3% 이하. 기한 방식으로 운영합니다. 11-03에 목표에 못 미쳐도 그때의 최선을 고정하고, 평가는 한 번만 한 뒤 결과를 그대로 적습니다.
- **앱 범위는 그대로**입니다. 카카오톡 알림만 읽고, 기기 안에서 판정하고, 인터넷 권한이 없고, 가족에게는 공유 버튼으로 알립니다.
