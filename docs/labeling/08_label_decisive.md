# 2단계 평가 라벨: 첫 결정적 지시 (KorCCVi 평가 통화 103건)

- 목적: 평가용 사기 통화마다 **첫 결정적 지시** 메시지 번호를 정합니다. 탐지율("그 메시지까지 경고했나", plan.md 7.2)을 재는 마감점입니다.
- 라벨러: ChatGPT·Gemini·Grok입니다. 프로젝트 밖에서 기억을 끄고 돌립니다. 이 세션(Claude)은 평가 통화를 보지 않으므로 라벨러에서 빠집니다.
- 정하는 방법:
  - 세 모델 중 둘 이상이 같은 번호를 적으면 그 값으로 정합니다.
  - 셋이 모두 다르면 사용자가 아래 기준 문장을 보고 판정합니다.
- 가림판: `tools/korccvi/make_label_pack.py`로 만듭니다(시드 20261028). 통화 103건을 글자 수가 비슷하게 4개 파일로 나눴습니다.
  - part1: T001–T038 (38건)
  - part2: T039–T065 (27건)
  - part3: T066–T084 (19건)
  - part4: T085–T103 (19건)
  - `blind_key.csv`(T번호 → 통화 ID)는 라벨러에게 주지 않습니다.

## 기준 (라벨을 받기 전에 확정, 2026-10-27)

**첫 결정적 지시** = "상대"가 "나"에게 **피해로 바로 이어지는 행동**을 처음으로 구체적으로 시킨 "상대" 메시지입니다.

| 종류(kind) | 해당 | 해당 아님 |
|---|---|---|
| 이체 | 돈을 다른 계좌로 옮기거나 보내라 ("안전계좌로 옮기세요", "이 계좌로 입금하세요", 대출금 상환금 입금) | 잔액이 얼마냐고 묻기만 함 |
| 현금 | 현금을 찾아라, 찾아서 누구에게 전달하거나 어디에 두라, 상품권을 사라 | "돈이 위험하다"는 겁주기만 함 |
| 앱 | 앱 설치, 링크 접속, 원격 제어 앱 실행, 특정 번호로 다시 전화하라 | 앱 이야기만 하고 설치하라고는 안 함 |
| 정보 | 계좌번호·카드번호·비밀번호·보안카드·OTP·인증번호·신분증 사진을 불러 주거나 보내라 | 이름·생년월일·주소만 확인, 사건 설명, 신원 확인 질문 |
| 대출 | 대출을 신청하라, 기존 대출을 갚으라(상환 지시), 대출 서류를 보내라 | 대출 상품 소개만 함 |
| none | 녹음이 잘려 위 지시가 끝까지 없음 | — |

- 같은 메시지에 여러 종류가 있으면 하나만 적습니다. 우선순위는 이체 > 현금 > 대출 > 앱 > 정보입니다.
- **"나"의 메시지 번호는 적지 않습니다.** 지시를 한 "상대" 메시지 번호를 적습니다.
- 화자를 자동으로 나눴기 때문에 틀릴 수 있습니다. 지시 내용이 "나"로 표시된 줄에 있으면, 그 줄 번호를 적고 reason에 "화자 뒤바뀜"이라고 씁니다.
- 지시가 여러 번 나오면 **가장 먼저 나온 것**을 적습니다.
- `none`인 통화는 탐지율 분모에서 빼지 않습니다. 대신 마감점을 "통화가 끝나기 전까지"로 둡니다.

## 라벨러에게 보낼 지시문

통화 파일 하나마다 새 대화를 열고, 아래 지시문과 `blind_partN.md`를 붙여 보냅니다.

```
[역할] 당신은 한국어 보이스피싱 통화 녹취를 라벨링하는 사람입니다.

[자료] 첨부한 blind_partN.md 에는 금융감독원이 공개한 실제 보이스피싱 통화를 음성 인식으로 받아 적은 글이 있습니다.
각 줄은 "번호 화자: 말"입니다. 화자는 자동으로 나눈 것이라 틀릴 수 있습니다 ("상대" = 사기범으로 추정한 사람).
받아 적기 오류(틀린 낱말)가 많으니 앞뒤 맥락으로 읽어 주세요.

[할 일] 통화마다 "첫 결정적 지시" 메시지 번호를 하나 정하세요.
첫 결정적 지시 = 상대가 "나"에게 피해로 바로 이어지는 행동을 처음으로 구체적으로 시킨 메시지.
kind는 아래 중 하나:
- 이체: 돈을 다른 계좌로 옮기거나 보내라 (안전계좌, 입금, 대출금 상환금 입금)
- 현금: 현금을 찾아라 / 찾아서 전달하거나 두라 / 상품권을 사라
- 대출: 대출을 신청하라 / 기존 대출을 갚으라 / 대출 서류를 보내라
- 앱: 앱 설치, 링크 접속, 원격 제어, 특정 번호로 다시 전화하라
- 정보: 계좌번호·카드번호·비밀번호·보안카드·OTP·인증번호·신분증 사진을 불러 주거나 보내라
- none: 녹음이 잘려 위 지시가 끝까지 없음
해당 아님: 이름·생년월일·주소만 확인, 사건 설명, 겁주기, 상품 소개만, 잔액을 묻기만 함.
규칙:
1. 가장 먼저 나온 지시를 고릅니다. 같은 메시지에 여러 종류면 이체 > 현금 > 대출 > 앱 > 정보 순으로 하나만.
2. "나"의 메시지가 아니라 지시를 한 "상대" 메시지 번호를 적습니다.
   단, 지시 내용이 "나"로 표시된 줄에 있으면(화자 뒤바뀜) 그 줄 번호를 적고 reason에 "화자 뒤바뀜"이라고 씁니다.
3. none이면 decisive_seq 칸을 비웁니다.

[출력] 이 파일에 있는 통화만, 아래 CSV로 돌려주세요. 통화 번호 순서대로, 빠짐없이.
call,decisive_seq,kind,reason
T001,12,이체,"안전계좌로 옮기라는 첫 지시"
(reason은 한 줄, 쉼표가 있으면 큰따옴표로 감쌉니다)
마지막에 기준으로 판단하기 어려웠던 점을 3줄 이내로 따로 적어 주세요.
```

## 받은 뒤
1. 형식을 확인합니다. 모델마다 103줄이어야 하고, 번호는 그 통화에 있는 번호여야 하며, kind 값이 목록 안에 있어야 합니다.
2. 일치율과 갈린 통화를 확인합니다. 셋이 모두 다른 통화와 none 여부가 갈린 통화를 판정 양식에 넣습니다.
3. 최종 라벨은 `data/eval/korccvi_labels/final_decisive.csv`에 둡니다. 통화 ID, 번호, 종류만 담고, 원문은 넣지 않습니다.
