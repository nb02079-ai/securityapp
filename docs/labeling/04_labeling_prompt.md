# 라벨링 진행 (작업 1단계 ③)

[03_label_guide.md](03_label_guide.md) 기준표로 재구성 사기 10건에 라벨을 붙입니다. 라벨러는 둘입니다.

| 라벨러 | 범위 | 보는 것 |
|---|---|---|
| 첫 번째: 새 Claude 세션 (프로젝트 밖) | 10건 전부 | 가림판 + 기준표 + 빈 시트 |
| 두 번째: 사용자 본인 | 5건 | 같은 가림판 + 기준표 + 빈 시트 (5건만) |

## 준비

가림판과 시트는 **번호를 섞은 판**(시드 `20261021`)으로 만듭니다. 섞은 가림판은 기록용으로 `docs/labeling/blind_cases_seed20261021.md`에 둡니다 (자유 메모 때의 `blind_cases.md`와 구분). 자유 메모 때의 번호(파일 순서)와 다르므로, 결과를 맞춰 볼 때는 번호표로 원래 사례 이름을 찾습니다.

```
python tools/scam/make_blind.py       data/eval/scam/*.jsonl --out "<저장소 밖>/label_in"  --shuffle-seed 20261021
python tools/scam/make_label_sheet.py data/eval/scam/*.jsonl --out "<저장소 밖>/label_all" --shuffle-seed 20261021
python tools/scam/make_label_sheet.py data/eval/scam/*.jsonl --out "<저장소 밖>/label_me"  --shuffle-seed 20261021 --cases <5건 번호>
```

### 두 번째 라벨러 5건을 고른 기준
- 자유 메모에서 "첫 이상 신호"가 세 모델 모두 달랐던 사례 (필수, plan.md 5.2)
- "첫 금전 요구"가 권유냐 구체 지시냐로 갈린 사례 2건
- 방이 여러 개인 가장 긴 사례
- 송금이 끝까지 없는 사례 (첫 송금 직전 규칙 3번 시험)

## 첫 번째 라벨러: 새 세션 진행 방법
1. **이 프로젝트 밖에서** 새 대화를 엽니다 (프로젝트 문서·기억에 있는 분석 결과가 섞이지 않게).
2. 아래 지시문을 붙여 넣고 섞은 가림판(`blind_cases_seed20261021.md`로 이름을 바꿔 둠), `03_label_guide.md`, `label_messages.csv`, `label_points.csv`를 첨부합니다. `blind_key.csv`는 넣지 않습니다.
3. 채워진 두 CSV를 받아 원래 세션으로 가져옵니다.

```
첨부한 대화 기록 파일(이름이 blind_cases로 시작하는 .md)에는 10개의 대화 기록(C01~C10)이 있습니다. 모두 실제 금융 사기 사례를 바탕으로 재구성한 것이고, "나"가 피해자입니다.
첨부한 03_label_guide.md(라벨 기준표)에 따라 라벨을 붙여 주세요.

[규칙]
- 기준표의 정의와 "붙이지 않는 경우"를 그대로 따르세요. 기준표에 없는 신호 코드를 만들지 마세요.
- 웹 검색을 하거나 원래 기사·사건을 추측해서 찾지 마세요. 표에 보이는 것만 보세요.
- 상대방 메시지 하나도 빠뜨리지 마세요. 신호가 없는 메시지는 signals 칸을 비우되 stage와 confidence는 채우세요.
- 확신이 없으면 confidence를 "낮음"으로 하고 note에 고민한 다른 신호를 적으세요.
- "보냈어요"가 돈을 보낸 것인지 반드시 확인하세요 (기준표 4.2).

[출력]
첨부한 label_messages.csv와 label_points.csv의 빈 칸을 채워 같은 이름의 CSV 파일 두 개로 돌려주세요.
- 줄을 추가하거나 지우지 말고, case·seq·room·sender·text 칸은 바꾸지 마세요.
- 모든 사례를 끝낸 뒤, 기준표로 판단하기 어려웠던 점을 5줄 이내로 따로 적어 주세요.
```

## 두 번째 라벨러: 본인 진행 방법
1. `label_me/label_messages.csv`, `label_me/label_points.csv`를 엑셀로 엽니다.
2. 섞은 가림판에서 해당 5건만 읽으며 기준표대로 채웁니다.
   - 원래 사례 파일(`data/eval/scam/*.md`)과 자유 메모 분석은 **라벨링을 마칠 때까지 다시 열지 않습니다.**
   - 새 세션의 결과를 보기 전에 끝냅니다.
3. CSV(UTF-8)로 저장해 원래 세션으로 가져옵니다.

**한계로 기록할 것**: 두 번째 라벨러는 사례 작성 세션과 대화를 나누며 자유 메모 분석을 이미 읽었습니다. 따라서 완전히 독립된 라벨러는 아니며, 일치율을 보고할 때 이 점을 함께 적습니다.

## 결과를 받은 뒤
- 일치율: 금전 지점 두 개(정확히 같은 번호 / ±1), 신호별 κ(메시지 × 신호의 있음·없음), 단계 κ
- 갈린 메시지는 두 라벨러의 메모를 보고 기준표 문구를 고칠지 정한다. **기준표를 고치면 고친 내용과 이유를 기록하고, 이미 붙인 라벨은 고친 기준으로 다시 확인한다.**
- 최종 라벨은 두 라벨러가 겹치는 5건은 합의로, 나머지 5건은 첫 번째 라벨러 결과를 기준표로 한 번 더 확인해 정한다.
