## 2. 사례별 정리

### C01
- 흐름: 무료 강의방에 초대해 출석 체크와 혜택 약속으로 묶어 둠 → 시황 분석·단타 종목을 주고 1:1로 매도 시점을 알려 수익을 맛보게 함 → 책·선물로 호의를 쌓고, 다른 회원이 받았다고 증언함 → 정부·기관이 받쳐 주는 비밀 프로젝트를 소개하며 500% 수익 보장과 비밀 유지를 요구함 → 회원들의 수익 인증과 금액별 분배 규칙으로 큰 금액을 유도한 뒤 지정 계좌로 입금받고, 다른 계좌로 추가 입금을 받음 → 출금을 요청하자 고객센터라는 상대가 보증금 50%를 요구함
- 첫 요구: 번호 12 — 선물을 준다며 주소(개인정보)를 받음. 다만 10번에서 책을 이미 받았으므로 주소는 그전에 넘어갔을 수 있음(?). 돈 자체의 첫 요구는 27번
- 첫 이상 신호: 번호 15 — 정부가 뒤에서 지원하는 비공개 투자라는 말은 확인할 길이 없고, 바로 17번의 수익 보장으로 이어짐

### C02
- 흐름: 은행 CEO 이름을 건 문자로 종목방에 끌어들임 → 실존 인물 기사와 연예인 회원으로 신뢰를 빌려 옴 → 종목을 찍어 주고, 손실이 나면 실제로 보상금을 넣어 줘 믿음을 쌓음 → 회원 전용 싼 공모주를 내세워 전용 사이트에 가입시키고 개인 계좌로 입금받음 → 대출로 규모를 키우게 한 뒤, 출금을 막고 더 투자해야 뺄 수 있다고 함
- 첫 요구: 번호 16 — 전용 사이트 가입으로 개인정보를 넘기게 함(?). 돈 자체의 첫 요구는 18번
- 첫 이상 신호: 번호 1 — 은행 CEO가 모르는 사람에게 문자로 종목을 추천할 리 없음

### C03
- 흐름: 피해자 모임 블로그를 보고 온 "나"를 맞아 사연을 들음 → 집단 소송과 보상확약서로 피해를 되찾아 주는 사람 역할을 함 → 실제로 확약서를 받게 해 믿음을 얻음 → 피해 회복 수단이라며 비상장주식을 대량으로 사게 함 → 거래를 묻자 세무조사 핑계로 막음
- 첫 요구: 번호 8 — 피해를 되찾으려면 비상장주식을 사라며 처음 돈을 쓰게 함 (10번에서 수량을 정함)
- 첫 이상 신호: 번호 4 — "투자 전문가"가 소송을 도와주겠다는 것은 역할이 맞지 않음(?). 8번에서 돕던 사람이 주식을 팔기 시작한 것은 더 분명한 신호

### C04
- 흐름: 해외에서 일하는 조향사라며 먼저 말을 걺 → 안부와 일 이야기로 친해짐 → 한국에 와서 살 계획이라며 미리 보낼 짐의 통관비를 대신 내 달라고 함
- 첫 요구: 번호 7 — 짐 통관비를 대신 내 달라고 함
- 첫 이상 신호: 번호 7 — 만난 적도 없는 사람이 자기 짐 비용을 대신 내 달라고 함 (1번의 낯선 해외인 접근도 약한 신호(?))

### C05
- 흐름: 한국어를 배우고 싶다며 접근하고, 거절당해도 다시 부탁해 대화를 이어 감 → 안부로 친해진 뒤 친척 성공담으로 코인을 권하고 계좌 개설을 직접 이끔 → 소액 수익과 출금을 경험시켜 믿게 함 → 금액을 늘려 지정 주소로 보내게 함 → 이벤트 링크를 누르게 한 뒤, 1억을 채우지 않으면 원금도 못 찾는다고 위협함
- 첫 요구: 번호 7 — 소액이라도 코인에 돈을 넣어 보라고 함
- 첫 이상 신호: 번호 7 — 한국어를 배우겠다던 사람이 갑자기 투자를 권함

### C06
- 흐름: 교포 대기업 엔지니어라고 소개 → 해외 현장 핑계로 영상통화를 피하면서 만남 약속을 잡았다가 취소함 → 여권 사진으로 신원을 증명하고, 이메일 대리 발송 같은 작은 부탁을 들어주게 함 → 큰 계약 위기와 막힌 계좌를 내세워 고이자로 300만 원을 빌림 → 택배사 문자와 함께 통관비를 추가로 받아 감
- 첫 요구: 번호 13 — 계좌가 막혔다며 300만 원을 보내 달라고 함
- 첫 이상 신호: 번호 3 — 영상통화가 계속 끊긴다며 얼굴 확인을 피함

### C07
- 흐름: 가벼운 인사 후 팬을 언급하며 비트코인 투자를 권하고, 거절해도 소액으로 설득함 → 회사 지갑과 직원 개인 계좌로 돈을 받음 → 출근 사진·명함·여권으로 진짜 사람처럼 보임 → 1억 원을 코인으로 바꿔 보내 달라고 했다가 거절당하자 사과함 → 그만하겠다는 말에 서운함·칭찬으로 붙잡고 남편에게 거짓말하라고 지시함 → 돈을 찾으려면 더 넣으라고 함
- 첫 요구: 번호 7 — 회사 지갑 주소로 돈을 보내라고 함
- 첫 이상 신호: 번호 3 — 처음 말을 건 사람이 팬 운운하며 투자를 권함

### C08

- 첫 요구: 번호 7 — 금을 보내는 배송비를 보내 달라고 함

### C09
- 흐름: 아는 사이에서 주식 대회 경력을 내세워 사업을 소개 → 월 40% 수익과 원금 보장을 약속하고 개인 계좌로 입금받음 → 실제 수익금을 보내 믿게 하고 더 넣으라고 권함 → 가족의 급한 사정으로 돈을 빌림 → 몇 달 뒤 코인 상장과 손실 보장을 약속하며 자료 파일을 보냄
- 첫 요구: 번호 6 — 자기 계좌로 투자금을 보내라고 함
- 첫 이상 신호: 번호 3 — 매달 40% 수익과 원금 보장을 함께 약속함

### C10
- 흐름: 광고를 보고 온 "나"에게 광고와 다른 영상 캡처 부업을 소개 → 전용 계정에 가입시키고 텔레그램 단체방으로 옮김 → 첫 캡처에 소액을 적립해 보상을 맛보게 함 → 입금하면 더 돌려준다는 과제와 최소 금액을 제시하고, 다른 회원들이 금액을 외침 → 은행 창구를 피해 ATM·인터넷뱅킹으로만 입금하라고 함 → 수익 구조 질문에는 답하지 않고 신분증과 전화번호를 요구함
- 첫 요구: 번호 3 — 전용 계정 등록으로 개인정보를 넘기게 함. 돈 자체의 첫 요구는 11번
- 첫 이상 신호: 번호 2 — 광고와 다른 일이고, 영상 캡처 한 장에 최대 8,000원은 너무 쉬운 돈
