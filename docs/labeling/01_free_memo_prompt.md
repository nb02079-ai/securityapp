# 자유 메모 지시문 (작업 1단계 ①)

plan.md 5.2의 "단계 체계 검증 후 라벨링" 1번 단계에 쓰는 지시문입니다. 사례를 쓴 세션이 아닌 **새 Claude 세션**에 `blind_cases.md`와 함께 넣습니다.

## 진행 방법
1. `tools/scam/make_blind.py`로 `blind_cases.md`(가림판)를 만든다. `blind_key.csv`는 넣지 않는다.
2. **이 프로젝트 밖에서** 새 대화를 연다. 프로젝트 안에서 열면 프로젝트 문서나 기억에 있는 신호 체계가 섞일 수 있다.
3. 아래 "지시문"을 그대로 붙여 넣고 `blind_cases.md`를 첨부한다.
4. 결과 파일 `memo_result.md`를 받아 원래 세션에 가져온다.

## 지시문

```
첨부한 blind_cases.md에는 10개의 대화 기록(C01~C10)이 있습니다. 모두 실제 금융 사기 피해 사례를 바탕으로 재구성한 것이고, "나"가 피해자입니다.

이 작업의 목적은 사기 대화에서 상대가 하는 행동을 정해진 분류 없이 있는 그대로 기록하는 것입니다. 아래 규칙을 지켜 주세요.

[규칙]
- 미리 정해진 분류나 단계 이름(예: 접근, 신뢰 형성, 유도 등)을 쓰지 마세요. 본인의 말로 쓰세요.
- 단어가 아니라 행동을 적으세요. "투자라는 단어가 나옴"이 아니라 "투자하면 큰돈을 번다고 약속함"처럼 쓰세요.
- 웹 검색을 하거나 원래 기사·사건을 추측해서 찾지 마세요. 표에 보이는 것만 보세요.
- 확실하지 않으면 메모 끝에 (?)를 붙이세요.

[1. 메시지 메모]
"나"가 아닌 사람이 보낸 모든 메시지에 대해, 보낸 사람이 그 말로 무엇을 하려는지 25자 이내로 적어 주세요.
"나"의 메시지는 메모하지 않아도 됩니다.

[2. 사례별 정리]
사례마다 다음 세 가지를 적어 주세요.
(a) 흐름 요약: 상대가 무엇을 어떤 순서로 했는지 3~6줄
(b) 처음으로 돈, 또는 돈으로 바뀔 수 있는 것(신분증, 계좌, 개인정보 등)을 요구한 메시지 번호와 이유 한 줄
(c) "나"의 입장에서 처음 이상하다고 느꼈어야 할 메시지 번호와 이유 한 줄

[3. 반복되는 행동]
10개 사례를 다 본 뒤, 여러 사례에서 되풀이되는 상대의 행동을 직접 묶고 이름을 붙여 주세요.
묶음마다 이름, 한 줄 설명, 해당하는 (사례, 메시지 번호) 목록을 적어 주세요.
어느 묶음에도 들어가지 않는 눈에 띄는 행동이 있으면 따로 적어 주세요.

[출력]
결과를 memo_result.md 파일 하나로 만들어 주세요. 형식은 다음과 같습니다.

## 1. 메시지 메모
| 사례 | 번호 | 메모 |
|---|---|---|
| C01 | 1 | ... |

## 2. 사례별 정리
### C01
- 흐름: ...
- 첫 요구: 번호 N — 이유
- 첫 이상 신호: 번호 N — 이유

## 3. 반복되는 행동
| 묶음 이름 | 설명 | 해당 (사례, 번호) |
|---|---|---|

## 4. 묶음에 안 들어간 행동
- ...
```

## 결과를 받은 뒤 (원래 세션에서)
- 3번 "반복되는 행동" 묶음을 plan.md 4.2.2 신호 체계 가설과 대조한다: 일치, 가설에만 있음, 메모에만 있음
- 2번 (b) "첫 요구" 번호를 라벨링 때 금전 요구 지점의 첫 번째 의견으로 쓴다
- 2번 (c) "첫 이상 신호"는 엔진이 경고를 내야 할 이상적인 시점의 참고값으로 쓴다
