# 대화 기록 (가림판)

각 사례는 한 사람("나")이 받은 메시지와 보낸 메시지를 시간 순서로 모은 것입니다.
- `dN`은 첫 대화로부터 며칠째인지입니다.
- `[사진]`, `[파일]`은 사진·파일이 왔다는 표시만 보이는 메시지입니다.
- `(링크)`, `(계좌번호)` 등은 원래 내용이 있던 자리를 가린 것입니다.
